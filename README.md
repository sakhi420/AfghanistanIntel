# AfghanistanIntel

یک مخزن برای جمع‌آوری، تحلیل و مستندسازی اطلاعات مرتبط با افغانستان. هدف این پروژه ارائهٔ منابع، اسکریپت‌ها، و تحلیل‌های کاربردی برای پژوهشگران، خبرنگاران، و علاقه‌مندان است.

## وضعیت

این مخزن تازه ایجاد شده و در مراحل اولیه است. فایل‌ها و دایرکتوری‌ها به مرور اضافه خواهند شد.

## ساختار پیشنهادی

- data/ : داده‌های خام (در صورت وجود)
- scripts/ : اسکریپت‌ها و ابزارهای پردازش داده
- docs/ : مستندات و یادداشت‌ها
- analysis/ : تحلیل‌ها، نتایج و گزارش‌ها

## راهنمای استفاده

1. مخزن را کلون کنید:

   git clone https://github.com/sakhi420/AfghanistanIntel.git

2. بسته به نیاز، وارد دایرکتوری مربوطه شده و اسکریپت‌ها را اجرا کنید.

3. اگر داده‌ای اضافه می‌کنید، ساختار پوشه `data/` را حفظ کنید و در صورت امکان یک فایل README درون آن قرار دهید تا منبع و فرمت داده مشخص باشد.

## مشارکت

ایده‌ها، باگ‌ها و درخواست‌های بهبود خوش‌آمدید. لطفاً Issue باز کنید یا Pull Request ارسال کنید. در PRها توضیح دهید که چه تغییری انجام داده‌اید و چرا.

## مجوز

در صورت تمایل مجوز پروژه را مشخص کنید. فعلاً هیچ مجوزی تنظیم نشده است — اگر مایلید یک مجوز (مثلاً MIT) اضافه کنم، بگویید.

## تماس

در صورت سوال یا پیشنهاد می‌توانید از بخش Issues استفاده کنید یا با صاحب مخزن تماس بگیرید.
